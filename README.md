# Authentication

Домашнее задание по теме hooks-context.

## Запуск

```bash
npm install
npm run dev
```

## Backend

Готовый сервер из задания лежит в каталоге `backend`. Запускается в отдельном терминале, порт 7070:

```bash
cd backend
npm install
npm start
```

Адрес сервера задан в файле `.env`.

Вход: логин `vasya`, пароль `password`.
